# ECE1724
This repository is the main workspace for ECE1724 final project. Team members can freely edit this document to add potential features, technology, or brainstorm.

After the kick-off meeting, the team agreed on a **Project Management** application. Some feature ideas:
* shared calendar with key dates of a project
* task assignment to team members
* project requirements and their compliance status
* dashboards, forecasts, data integration of task status
